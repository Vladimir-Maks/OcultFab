# OcultFab

> Компании **Ocult Inc** требуются аспиранты для проведения добычи ресурсов и их обработки в условиях повышенной **ДЕМОНИЧЕСКОЙ** опасности!!!

### ТРЕБОВАНИЯ

- уметь призывать **ПРИХВОСТНЕЙ** и командовать ими
- базовые знания **ОКУЛЬТНОЙ** инженерии и минералогии (в алхимии)

### БУДЕТ ПЛЮСОМ

- не бояться **ОГРОВ**, **СКЕЛЕТОВ** и других пещерных монстров!
- не требовать зарплату

### ВАШИ ОБЯЗАННОСТИ

- **ЗАЩИЩАТЬ** магорубиновое **ЯДРО**
- **СТРОИТЬ** сооружения для защиты и переработки ресурсов
- иногда **ПРОКЛАДЫВАТЬ ТРУБЫ**

## Лицензия

Весь проект доступен под лицензией **GPLv2**, включая ассеты.

Некоторые текстуры переделаны или взяты на основе текстур движка VoxelCore (как, допустим, текстура труб), следовательно, распространяются на основе их оригинальной лицензии.

Проект подготовлен специально для 14-дневного геймджема VoxelCore по тематике — небольшая игра по теме заводов типа Mindustry либо Factorio.
